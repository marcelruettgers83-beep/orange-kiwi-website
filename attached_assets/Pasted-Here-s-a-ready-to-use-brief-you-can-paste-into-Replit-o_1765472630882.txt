### PROJECT BRIEF – ORANGE KIWI WEBSITE V1

**Goal:**
Build a modern, responsive one-page website for **Orange Kiwi** (accounting / management accountancy firm).

---

## 1. Tech & Layout

* Stack: HTML + CSS (and minimal JS for smooth scrolling / mobile nav). No backend needed.

* Layout: One-page scrolling site with these sections:

  1. Sticky header / navigation
  2. Hero
  3. Who We Are
  4. Services (cards grid)
  5. How We Work (4-step process)
  6. Testimonials (placeholder cards for now)
  7. Final CTA section + footer

* Fully responsive:

  * Desktop: 2–3 column grids for services.
  * Tablet: 2 columns.
  * Mobile: 1 column stacked, mobile menu.

---

## 2. Brand & Styling

* **Primary accent colour:** orange (use something like `#f97316` or similar); use it for buttons, icons, section labels, progress dots, etc.
* **Secondary colour:** dark grey / charcoal for text, light grey backgrounds (`#f5f5f5` style).
* **Typography:** clean sans-serif (e.g. Inter, Roboto or similar).
* **Cards:** rounded corners, soft shadow, white background, subtle hover effect.
* **Buttons:** pill or rounded buttons with solid orange background and white text, hover = slightly darker orange.
* Overall feel: modern, trustworthy, professional, but not corporate-cold.
